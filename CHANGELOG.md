## 1.0.0

First public release.

- GPU recording: NVIDIA NVENC (H.264 / HEVC / AV1), Intel Quick Sync, AMD AMF (experimental), CPU x264 fallback
- Display or region capture, 30–144 fps, MP4 / MKV
- Live drawing tools with per-tool fade, undo / redo, clear
- Zoom into an area while recording; magnifier lens (toggle or hold)
- Keystroke overlay incl. modifier + mouse combos; cursor highlight with click ripples
- Webcam bubble with iris animation; system audio and microphone with mute
- Pause / resume with cursor restore; private mini control bar
- Global hotkeys (reserved only while recording); English / Turkish UI
- Built-in update check via GitHub Releases and *Report a problem* button
